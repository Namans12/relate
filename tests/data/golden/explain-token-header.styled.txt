ADR-0585  The installer downloads release assets over the direct route
          [Proposed]
  rule     install.sh consults no GitHub API endpoint and does not read
           GITHUB_TOKEN
  why      Anonymous GitHub API requests are limited to 60 per hour per IP
           address, and users behind shared egress (VPNs, corporate NAT,
           Cloudflare WARP) exhausted that quota, so the one-line installer
           broke. Release assets are now fetched over the direct download route
           instead. Only ADR-0068's installer authentication clause is
           superseded; version selection still uses releases.json.

How it works

Three steps, one graph.

Cite

Every ADR mention in Relate's repo, plus hand-reviewed rules and the tests that enforce them.

Replay

Each patch runs against the unmodified upstream test harness in its own clean checkout.

Explain

One Relate query joins the patch, its decision and every observed test result.

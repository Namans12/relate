Use it

Run it in a minute.

macOSgituvno API key
1

Clone

macOS with git and uv. The first run also downloads Relate's source once.

terminal
$ git clone https://github.com/Namans12/relate.git
$ cd relate
2

Run the demo

Replays every patch against the real upstream tests and explains the result. About 45 seconds.

terminal
$ uv run patch-precedent demo all

scenario   runs  matched  exit
installer  4     4/4      0
release    4     4/4      0
3

Explain any patch

Read-only and offline. Works on any diff against Relate.

terminal
$ uv run patch-precedent explain fixtures/installer/token-header.patch
4

Give your agent the graph

One read-only tool, precedent_for_patch. Run the demo first so it can return observed results.

.mcp.json
{
  "mcpServers": {
    "precedent": {
      "command": "uv",
      "args": ["run", "--project", "<path-to-relate-clone>",
               "--quiet", "patch-precedent", "mcp"]
    }
  }
}
or in one line
$ claude mcp add --scope project precedent -- uv run --project <path-to-relate-clone> --quiet patch-precedent mcp
5

Relate's own MCP server

Raw Cypher over the same graph. Point it at a copy of the store.

optional, macOS arm64
$ uv run patch-precedent fetch-relate-cli
$ <path printed above> serve --mcp stdio --read-only --database <copy of data/precedent.rl>
6

Re-score the published evaluation

Rebuilds RESULTS.md byte for byte from the committed transcripts.

offline, no usage
$ uv run patch-precedent eval score --results eval/results/20261127T040059Z
$ uv run patch-precedent eval report --results eval/results/20261127T040059Z

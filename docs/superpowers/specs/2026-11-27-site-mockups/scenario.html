ADR-0585 · The installer downloads release assets over the direct route

Anonymous GitHub API requests are limited to 60 per hour per IP address, and users behind shared egress (VPNs, corporate NAT, Cloudflare WARP) exhausted that quota, so the one-line installer broke.
